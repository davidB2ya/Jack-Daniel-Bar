## Cómo Usar los Vectores en tu Sitio

### Opción 1: Descarga y Usa Directamente
1. Descarga el SVG desde cualquier sitio
2. Guarda en la carpeta de tu proyecto (ej: `images/`)
3. Usa en HTML: `<img src="images/cocktail.svg" alt="Coctel">`

### Opción 2: Inline SVG
1. Copia el código SVG
2. Pégalo directamente en tu HTML
3. Personaliza colores con CSS

### Opción 3: Background CSS
```css
.seccion {
    background-image: url('images/patron-bar.svg');
    background-repeat: repeat;
}
```
